# Листай — генератор каруселей из текста

Веб-инструмент: вставил текст → получил готовые слайды карусели для Instagram, Telegram, LinkedIn, VK. Работает целиком в браузере, без сервера и регистрации.

## Возможности

- Текст → слайды: пустая строка = новый слайд, первая строка = заголовок, `- ` = список, `==слово==` = выделение цветом, `**слово**` = жирный.
- Дизайн-система «Нейро» из проекта нейро-карточек: кобальт #1F3DFF, Unbounded 900 + Manrope, пилюли, тёмный блок под тезис, 3D-объекты (шар, тор, капсула, куб, пружина, хром) в векторе. Она же в интерфейсе.
- Форматы 4:5, 1:1, 9:16. 18 тем в стилях узнаваемых брендов (швейцарская типографика, банковский жёлтый, корпоративный синий, газета, глянец, спорт, брутализм и другие). 9 компоновок слайда: стандарт, с номером, две колонки, цитата, крупная цифра, чеклист, карточка, рамка, линейки.
- Свои цвета, пять пар шрифтов, узоры фона, выравнивание. Бренд-кит сохраняется и подставляется в каждую новую карусель.
- Редактор слайда как в Canva: слева панель инструментов, в центре холст, справа свойства, внизу лента слайдов для переключения. Заголовок и текст двигаются по области, слои с текстом, картинками, прямоугольниками, кругами, линиями и стикерами. Перетаскивание, изменение размера за уголки, поворот, прозрачность, порядок слоёв, дублирование, «на все слайды». Сетка 12 колонок, безопасная зона для сторис, привязка к краям, центру и сетке с направляющими. Undo/redo, стрелки, Delete, Ctrl+D, Ctrl+G.
- Фоновая картинка с затемнением, положение текста, «текст под слоями», перестановка, дублирование и удаление слайдов.
- Логотип на всех слайдах, аватар и имя автора, карточка «Подписаться» на последнем слайде.
- Пять шаблонов структуры и банк из 36 идей по шести нишам.
- Проверка перед публикацией: балл 0–100 и список подсказок (длина заголовка, число слайдов, призыв, выделения).
- Экспорт: PNG-архив и PDF-документ для LinkedIn. Подпись к посту одной кнопкой.
- «Мои карусели»: все проекты сохраняются в браузере, можно открыть, скопировать, удалить. Проект также сохраняется и открывается файлом.
- Устанавливается как приложение (PWA) и работает офлайн.
- Отдельная страница «Стикеры» (`docs/stickers.html`): фото → кадрирование с зумом и панорамой → форма (квадрат, скругление, круг, вырез фона) → белая обводка как в Telegram → надпись в одном из шести шаблонов (мем, плашка, нейро, пузырь, штамп, полоса) → PNG 512×512 для Telegram и WhatsApp. Пак собирается в ZIP. Удаление фона включается отдельной кнопкой, а не при загрузке. Два способа: нейросеть MediaPipe для фото людей (модель 6 МБ лежит в `docs/vendor/mp`, грузится по нажатию, работает офлайн) и заливка однотонного фона по краям (цвет берётся медианой по рамке, область растёт по локальной похожести, края мягкие). После любого способа доступна кисть «стереть/вернуть» и кнопка «Вернуть фон».
- Карточки редактируются на месте: под каждой заголовок, текст, чипы компоновки (стандарт, цитата, цифра, чеклист, номер, карточка), переставить, добавить, удалить. Полный текст свёрнут в «Весь текст целиком». На телефоне список карточек идёт первым: один экран = одна карточка.
- 24 готовых макета (тема + компоновка + украшения сразу для всех слайдов) с живыми превью на вашем тексте.
- В редакторе: 93 векторные иконки в цвете темы, QR-код по ссылке, 3D-объекты. QR на последний слайд ставится одним полем в форме. Номер слайда на стрелке «листай».
- Экспорт: PNG-архив, PDF, PPTX и DOCX для LinkedIn, видео MP4 (H.264 через WebCodecs, при отсутствии кодека VP9 или WebM) с плавными переходами и полями под Reels 9:16. Тяжёлые библиотеки грузятся только по нажатию.
- История версий проекта (до 12, не чаще раза в две минуты) и ссылка на проект: текст и настройки упакованы прямо в адрес, сервер не нужен.
- 16 формул хуков для обложки и 8 готовых призывов в поле CTA.
- Интерфейс на русском и английском.

## Включить сайт (одно действие, 30 секунд)

GitHub не даёт включить Pages из автоматики, это делает владелец репозитория один раз:

1. Откройте https://github.com/yangorovet-lab/m20-/settings/pages
2. Source: **Deploy from a branch**. Branch: **claude/blissful-mayer-j1gyhc**, папка **/docs**. Нажмите Save.
3. Через 1–2 минуты сайт откроется по адресу выше. Дальше каждый push обновляет его сам.

Альтернатива: выбрать Source **GitHub Actions**, тогда сработает готовый workflow `.github/workflows/pages.yml` (перезапустите его во вкладке Actions).

## Как включить продажи (10 минут)

Сейчас продукт работает в полностью бесплатном режиме: без водяного знака, все темы открыты. Это сделано специально, чтобы первые пользователи приходили без трения. Чтобы включить монетизацию:

1. Создайте товар «Листай Pro, $9, разовая оплата» на любой площадке, которая выдаёт ссылку на оплату: Gumroad, Lemon Squeezy, Boosty, Tribute, Продамус.
2. В `docs/config.js` вставьте ссылку в `payUrl` и смените `licenseSecret` на свою случайную строку.
3. Сделайте push. Сайт обновится сам через 1–2 минуты.

После этого у бесплатных пользователей появится водяной знак, темы «Неон», «Закат», «Плекс» и экспорт в PDF закроются, в шапке появится кнопка «Pro · $9».

### Выдача ключей

Покупатель оставляет e-mail при оплате. Вы генерируете ключ и отправляете письмом:

```
LISTAI_SECRET="ваш-секрет" node tools/keygen.js buyer@example.com
# → A1B2-C3D4-E5F6-A7B8
```

Покупатель нажимает «Уже есть ключ», вводит e-mail и ключ. Ключ хранится в его браузере.

Ограничение схемы: секрет лежит в клиентском коде, поэтому технически подкованный человек может сгенерировать ключ сам. Для продукта за $9 это приемлемый компромисс: защита от «случайного» обхода есть, сервер не нужен. Если продажи пойдут, следующий шаг — проверка ключа через API площадки (у Gumroad и Lemon Squeezy есть встроенные лицензии).

## Честно про деньги

Никакой инструмент не гарантирует доход. $50 в день при цене $9 — это примерно 6 продаж в день, то есть при типичной конверсии 1–2 % около 300–600 посетителей в день. Это достижимо, но только с трафиком. Продукт готов, трафик — ваша часть работы. Что даёт результат быстрее всего:

1. **Свои соцсети.** Каждый пост в Telegram/Instagram/LinkedIn делайте этим инструментом и подписывайте «сделано в Листай + ссылка». Это бесплатная реклама с каждого поста.
2. **Сообщества SMM и копирайтеров.** Telegram-чаты SMM-щиков, VC.ru, Хабр (Карьера/Маркетинг), Pikabu, Reddit r/socialmedia и r/Instagram, Product Hunt. Формат: не «вот мой продукт», а «сделал бесплатный инструмент, вот 5 каруселей, которые он собрал за минуту».
3. **SEO.** Страница уже оптимизирована под запросы «генератор каруселей», «карусель для инстаграм онлайн», «carousel maker». Добавьте 3–5 статей-инструкций в папку `docs/` (например «как сделать карусель для Telegram»), и через 1–3 месяца пойдёт органика.
4. **Партнёрка.** Предложите авторам SMM-каналов 50 % с продаж по их ссылке (Gumroad и Lemon Squeezy умеют партнёрские ссылки из коробки).
